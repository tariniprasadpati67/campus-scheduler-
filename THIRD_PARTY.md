# Third-Party Libraries and Dependencies

This document tracks all third-party libraries and tools used across the CIT Campus Scheduling Platform as required by Working Rule 7.

## Backend Stack
- **FastAPI**: Modern, fast web framework for building APIs with Python
- **Uvicorn**: Lightning-fast ASGI server implementation
- **SQLAlchemy**: SQL toolkit and Object Relational Mapper (ORM)
- **python-dotenv**: Loads environment variables from `.env`
- **PyJWT**: JSON Web Token implementation for authentication and role verification
- **passlib**: Password hashing framework supporting bcrypt
- **bcrypt**: Modern password hashing library
- **groq**: Official Python SDK for the Groq Cloud API
- **ortools (Google OR-Tools)**: CP-SAT constraint programming solver
- **httpx**: Fully featured HTTP client library for FastAPI testing
- **python-multipart**: Streaming multipart parser for file and form data
- **psycopg2-binary**: PostgreSQL database adapter for Python
- **psycopg[binary]**: Modern PostgreSQL 3 database adapter for Python and SQLAlchemy 2.0+

## Frontend NPM Packages (Step 3b Viewer)
- **react** (`^18.3.1`): Declarative UI library
- **react-dom** (`^18.3.1`): React rendering engine for the DOM
- **vite** (`^5.4.2`): Frontend build tool and development server
- **@vitejs/plugin-react** (`^4.3.1`): Vite React plugin with Fast Refresh
- **tailwindcss** (`^3.4.10`): Utility-first CSS framework
- **postcss** (`^8.4.41`): Tool for transforming CSS with JavaScript
- **autoprefixer** (`^10.4.20`): PostCSS plugin to parse CSS and add vendor prefixes
